# Credit Score Prediction using Machine Learning

## Project Overview
This project predicts a customer's credit score category (Average, High, or Low) using machine learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Random Forest Classifier
- Google Colab

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Model Training
6. Cross Validation
7. Model Evaluation
8. Credit Score Prediction

## Machine Learning Algorithm
Random Forest Classifier

## Output
The model predicts the credit score category:
- Average
- High
- Low

## Project Type
Machine Learning – Classification
